# termpencil

`termpencil` is a fun lil project for making terminal/ASCII-style graphics, mockups, and more.

## What it does

- Create terminal and ASCII art-style graphics.
- Export preview scripts you can run directly in your terminal.
- Export binary files that can be loaded back into the tool for further editing. (or previewed as-is)
- Supports 256 terminal colors.

## How to use

The tool can be found live [here](https://termpencil.adiron.me). You can also clone this repo and `npm run dev` or `npm run build` to get a production build to host yourself.

To preview an existing .tp binary: `npm run tp:preview -- path/to/file.tp`
