# termpencil

`termpencil` is a fun hobby project for making terminal/ASCII-style graphics, mockups, and more.

## What it does

- Create terminal and ASCII art-style graphics.
- Export preview scripts you can run directly in your terminal.
- Export binary files that can be loaded back into the tool for further editing.
- Supports 256 terminal colors.
